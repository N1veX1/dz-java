эта программа создана для поиска приближенного корня нелинейного уравнения методом простых итераций. код находит решение для заданной кубической функции на выбранном числовом отрезке с высокой точностью. вычисления автоматически прекращаются при достижении нужной точности или при превышении лимита шагов. результат выводится на экран
описание алгоритма по пунктам
первое это задаются начальные данные границы отрезка стартовая точка точность вычислений и максимальное количество шагов
второе это исходное уравнение перестраивается в итерационную форму для выражения неизвестного икса
третье это запускается цикл в котором на каждом шаге вычисляется новое приближенное значение корня
четвертое это программа сравнивает разницу между новым и прошлым значением с заданной точностью
пятое это если разница стала меньше точности то цикл прерывается и программа выводит ответ на экран
шестое это если цикл сделал максимально допустимое число шагов но точность не достигнута то вычисления останавливаются с сообщением об ошибке
