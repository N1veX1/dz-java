Метод Ньютона

Программа находит корень уравнения 2x минус 1 делить на тангенс x равно нулю на отрезке от нуля до единицы.
Пользователь вводит требуемую точность вычислений. Начальное приближение равно 0.5.
Сначала программа задаёт начальное приближение. Затем вычисляет новое значение по методу Ньютона. Вычисления повторяются, пока значение функции не станет достаточно близким к нулю. После этого программа выводит найденный корень.
